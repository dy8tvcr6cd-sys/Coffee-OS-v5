# CoffeeOS Ultra v4

수정 반영:
- 진입 애니메이션은 최초 접속 또는 QR 진입에서만 실행
- 페이지 이동 시 인트로 재실행 없음
- 한국어/영어/일본어 전체 고정 UI 문구 번역 구조 적용
- placeholder 문구까지 다국어 적용
- 실제 데이터가 들어왔을 때 즉시 점수화 가능한 취향 분석 구조
- 로스터리별 원두 판매 페이지 추가
- 앱 내 결제가 아니라 로스터리 구매 사이트 이동 구조


## Intro behavior fixed
- 인트로 애니메이션은 같은 브라우저/기기 기준 최초 접속 1회만 실행됩니다.
- QR 버튼, QR 링크, 메뉴 이동, 페이지 전환에서는 인트로가 다시 실행되지 않습니다.
- 기준 저장소는 localStorage의 `coffeeos_intro_seen` 값입니다.


## Final fix
- 인트로가 끝난 뒤 반드시 페이지가 열리도록 수정했습니다.
- 인트로는 최초 접속 1회만 실행됩니다.
- 새로고침 시 마지막으로 보던 페이지가 열립니다.
- QR 버튼은 인트로 없이 원두 페이지로 이동합니다.


## v5 Neutral Design / Intro Review
- 인트로는 앱명 CoffeeOS 중심으로 변경했습니다.
- 원두명은 인트로에서 제거했습니다.
- 인트로는 최초 앱 접속 1회만 실행됩니다.
- QR 버튼, QR 링크, 메뉴 이동, 페이지 이동에서는 인트로가 다시 실행되지 않습니다.
- 색상은 특정 로스터리 색에 종속되지 않도록 뉴트럴/스톤/차콜 계열로 재정리했습니다.
- 컵노트 색상은 과한 원색 대신 중립 팔레트 안에서만 표현됩니다.
